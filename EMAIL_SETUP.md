# Tennis GO 0.30.0 — регистрация без Telegram

На сайте добавлены «Создать аккаунт по email» и «Забыли пароль?».
Пользователь вводит email, получает шестизначный код, задаёт пароль, затем выбирает роль и заполняет прежнюю анкету. Телефон для записи остаётся обязательным; Telegram у тренера теперь необязателен. Представитель клуба проходит прежнее одобрение администратора.

Email показывается только владельцу профиля. Код действует 10 минут, даёт 5 попыток, связан с браузером и используется один раз. Повторная отправка — не чаще раза в минуту. Аккаунт создаётся только после подтверждения. При восстановлении пароля старые веб-сессии отзываются.

## Подключить письма
В сборке используется HTTPS API Resend. Доступа к вашему почтовому сервису у разработчика нет, поэтому настоящая отправка ещё не включена.

1. Создайте аккаунт на https://resend.com и подтвердите домен отправителя в разделе Domains, добавив выданные сервисом DNS-записи.
2. Создайте API-ключ с правом отправки писем.
3. В Variables существующего сервиса Railway добавьте:

```
RESEND_API_KEY=ключ_из_Resend
EMAIL_FROM=Tennis GO <noreply@ваш-подтверждённый-домен>
```

Указанный адрес — шаблон: подставьте свой подтверждённый домен. Не используйте чужой домен или адрес @gmail.com/@mail.ru как отправителя. Тестовый отправитель Resend предназначен для тестов и не заменяет настройку для всех пользователей.

Домен для писем может отличаться от адреса сайта. Сайт может остаться на railway.app, но DNS домена railway.app вам не принадлежит и подтвердить его для отправки писем нельзя. Пока своего домена нет, для этой интеграции сначала потребуется домен отправителя.

4. Загрузите обновлённый проект в текущий репозиторий и выполните redeploy, сохранив прежний Volume и DB_PATH. Новые таблицы создадутся автоматически.
5. /api/config должен показывать version 0.30.0 и emailRegistration true (означает наличие настройки, а не проверку доставки). Откройте сайт в отдельном окне, зарегистрируйтесь на свою почту и проверьте доставку, вход и восстановление.

Секрет API храните только в Railway Variables, не в GitHub и не в переписке.

## Совместимость
Профили, записи, чаты, рейтинг и баллы всех пользователей остаются в общей базе. Пользователи сайта общаются с Telegram-пользователями через тот же чат приложения. Для аккаунтов без Telegram уведомления доступны на сайте под колокольчиком; этот выпуск отправляет email только для подтверждения и восстановления, не для игровых напоминаний.

Существующий Telegram-профиль лучше открывать кнопкой «Войти через Telegram». Регистрация через email создаёт отдельный аккаунт; автоматического объединения профилей по имени или телефону нет.

## Проверки и границы
Тесты доставки используют имитацию API почтового сервиса: реальные письма никому не отправлялись. Проверены регистрация всех ролей без Telegram, вход по email, повторное использование кода, лимит попыток, срок действия, восстановление, ошибка доставки и защита чужого аккаунта. Развёртывание в вашем Railway и проверка реальной доставки ещё не выполнены.
