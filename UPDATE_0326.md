# Tennis GO 0.32.6

- Нажатие на фото в круглой аватарке открывает исходное сохранённое изображение без обрезки. Новые фото сохраняются без квадратной обрезки (до 1200 пикселей по длинной стороне). Ранее сохранённую квадратную обрезку восстановить невозможно — для полного кадра загрузите фото заново. Просмотр на весь экран, переключение исходного размера, закрытие кнопкой, фоном или Escape.
- Новость с призывом создавать игры, участвовать в тренировках и получать баллы; информация о переговорах с кортами. Добавляется однократно при запуске обновлённого сервера, включая существующие базы. Массовая рассылка не отправляется.
- Рекомендации: сначала игры, затем тренировки. Внутри группы: подходящий NTRP, расстояние до корта события, затем время. Без геолокации — NTRP и время. Поиск игр использует тот же порядок; календарь и ближайшая собственная запись остаются хронологическими.

Замените файлы в GitHub и дождитесь развёртывания Railway. Сохраните DB_PATH=/var/data/tennis-go.sqlite и подключённый Volume /var/data. Архив не содержит базы пользователей.
