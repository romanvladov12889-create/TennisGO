# Tennis GO · Telegram Mini App MVP

Рабочий Mini App для Краснодара: найти игру, создать матч, занять место, поделиться приглашением; отдельный путь для заявки на тренировку (тренер → корт → дата/время). Для одиночной рейтинговой игры счёт подтверждает второй игрок, после чего Elo для соответствующего вида спорта меняется у обоих. Данные хранятся на сервере в SQLite.

## Быстрый запуск на Windows

1. Установите Node.js **24 или новее**.
2. Распакуйте архив и откройте терминал в папке `tennis-go-miniapp`.
3. Дважды нажмите `RUN_DEMO.bat`: он проверит Node.js, дождётся запуска сервера и откроет браузер. Установка пакетов не нужна.
4. Адрес серверной версии: `http://localhost:3000`. Если Node.js не установлен, откроется `OPEN_DEMO.html` — локальная версия интерфейса без общего сервера. Можно также открыть этот файл напрямую.

В серверной версии без `BOT_TOKEN` включён демо режим: показаны две примерные игры, доступна запись в локальную БД. Чтобы имитировать второго игрока, откройте серверный адрес в другом браузере или приватном окне. `OPEN_DEMO.html` предназначен только для просмотра и локальной проверки интерфейса; разные устройства не видят его данные. Данные находятся в `data/tennis-go.sqlite`. Пустая база создаётся автоматически. Для повторного запуска данных удалять не нужно.

Для публикации на Railway откройте `RAILWAY_DEPLOY.md`: там пошаговые действия от загрузки кода до кнопки бота.

## Подключение к Telegram

1. Создайте своего бота через **@BotFather** (`/newbot`) и запишите токен и имя бота. Токен никому не отправляйте и не добавляйте в архив или Git.
2. Разместите этот Node.js сервер на **публичном HTTPS адресе**. Хостинг должен поддерживать Node 24 и постоянное хранилище для SQLite. Путь к базе задайте переменной `DB_PATH`, например `/var/data/tennis-go.sqlite`. `PORT` берётся из окружения хостинга.
3. Задайте на сервере переменные `BOT_TOKEN` и `BOT_USERNAME` (имя без `@`). Перезапустите сервер. При наличии `BOT_TOKEN` демо доступ отключён, все API запросы проверяют подписанные Telegram `initData` и срок сессии.
4. В **@BotFather** установите меню бота командой `/setmenubutton`, выберите бота и укажите полный HTTPS URL Mini App. Также обязательно настройте **Main Mini App** в Bot Settings: ссылка приглашения `?startapp=game_UUID` открывает именно его.
5. Откройте бота в Telegram и нажмите кнопку меню. Созданная игра получит ссылку вида `https://t.me/ИМЯ_БОТА?startapp=game_UUID`, которую можно отправить в чат.

**Важно:** `localhost` работает только для просмотра в обычном браузере. Telegram требует доступный HTTPS URL. На бесплатном хостинге без постоянного диска база может сброситься при перезапуске. Заявка на тренировку пока сохраняется без проверки реального расписания и без платежа. Примерные карточки существуют только в демо режиме.

## Проверка

`npm test` проверяет создание игры, вход второго игрока, защиту от повторного входа, подтверждение счёта и изменение рейтинга, а также проверку подписи Telegram.

## Файлы

- `server.mjs` — HTTP API, Telegram авторизация, SQLite.
- `public/` — адаптивный интерфейс и изображения.
- `test/` — проверки ключевых сценариев.

Площадки в выпадающем списке сверены с сайтами клубов: [Динамо](https://dinamokuban.ru/), [Вопреки](https://xn--80aaghfbtclgs0ano5t.xn--p1ai/), [Сетбол](https://centr-setbol.ru/), [360° Падел](https://360padel.ru/), [XFit Юбилейный](https://padel-tennis-xfit-umr.xfitkrasnodar.ru/). Адреса зафиксированы в `public/courts.json`; статус свободных слотов не подключён. Подсказки для тенниса адаптированы по [шкале NTRP USTA](https://playtennis.usta.com/bemidjiareatennisassociation/CourtsandNTRP/NTRPRating), для падела используются отдельные условные ориентиры.
