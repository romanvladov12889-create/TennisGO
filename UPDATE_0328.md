# Tennis GO 0.32.8
Кнопка меню Telegram автоматически получает название «Запустить приложение» при запуске бота. Текущая HTTPS-ссылка кнопки сохраняется; если кнопка ещё не настроена, используется APP_URL или RAILWAY_PUBLIC_DOMAIN. При ошибке настройка повторяется, работа бота продолжается.
Для немедленной ручной замены: @BotFather → /setmenubutton → выбрать бота → текущая ссылка приложения → Запустить приложение.
